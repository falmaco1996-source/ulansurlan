# Website Profil DPRD (Vite + React + Tailwind)

## Jalanin di laptop

1. Install Node.js (versi LTS).
2. Masuk folder project lalu install dependency:

```bash
npm install
```

3. Jalankan dev server:

```bash
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

Output production ada di folder `dist/`.

## Deploy cepat

### Opsi A — Vercel
- Import repo GitHub
- Framework: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`

### Opsi B — Netlify
- New site from Git
- Build Command: `npm run build`
- Publish directory: `dist`
